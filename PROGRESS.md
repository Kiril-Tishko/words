## Resume
1. Re-run the first check on `first_pass_todo` (workflow script `tools/workflows/check-batches.js`, args `{"tag": "...", "batches": [...]}`).
2. Run `python3 tools/make_cross_batches.py`, then the cross-check on the new and unfinished `cross-*` batches.
3. Run the remaining sweeps, then `python3 tools/check_gaps.py`. Check the resulting `gapverify-*` batches with the first-check workflow, then cross-check them.
4. Run `python3 tools/build_site.py`.
